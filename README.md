# Kiran M. — Portfolio

A responsive portfolio based on the supplied résumé, with a forest green, ivory, and lime design. No installation or build step is needed. Styling and JavaScript are included in index.html. Your portrait is profile.jpg. The résumé download requires resume.pdf beside index.html.

## Preview on your computer

Open index.html in a browser after extracting the ZIP. Keep resume.pdf and profile.jpg in the same folder.

## Publish on GitHub Pages

1. Extract Kiran-Portfolio-GitHub.zip on your computer.
2. Sign in to GitHub and create a repository named `kiran-portfolio`. A public repository works with GitHub Free.
3. In the repository, select **Add file → Upload files**.
4. Upload `index.html`, `profile.jpg`, `resume.pdf`, and `README.md` from the extracted folder directly to the repository root. Do not upload the ZIP or place the files inside another folder. Commit the changes to `main`.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose **main** and **/(root)**, then click **Save**.
8. Once deployment finishes, open the website URL shown in Pages settings. For a repository named `kiran-portfolio`, it normally follows `https://YOUR-USERNAME.github.io/kiran-portfolio/`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Updating your portfolio

- Edit index.html to change the text, contact number, colours, or LinkedIn URL.
- Replace resume.pdf to update the download, retaining that exact filename.
- Commit changes to main; GitHub Pages will publish them.
- To diagnose a deployment error, review the repository's Actions tab.
